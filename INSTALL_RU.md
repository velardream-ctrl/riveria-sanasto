# Riveria Sanasto — установка первой версии (v1.0)

## Что это

Лёгкое учебное PWA-приложение для компьютера, телефона и планшета. Основа: ваша Google-таблица Riveria Sanasto (снимок данных от 1 ноября 2026 года): 1038 терминов, 84 обычные фразы, 183 образца записей Mediatri, 212 ключевых слов Mediatri, 40 ситуаций и 21 заголовок интерфейса.

**Работает:** карточки в обе стороны, тест с четырьмя ответами, поиск, добавление своих слов, избранное, статистика, упражнения Mediatri, словарь заголовков, поиск подходящих готовых фраз по русскому описанию, резервное копирование и восстановление.

**Ещё не подключено:** автоматическая синхронизация с Google Sheets. Новые слова и прогресс хранятся локально на каждом устройстве. Доступна ручная выгрузка новых слов в TSV, а всей локальной статистики — в JSON. НЕ помещайте в публичный репозиторий пароли, токены, Google API-ключи или личные данные пациентов.

## Самый короткий способ попробовать на Mac

Откройте файл `Riveria-Sanasto-PROBE.html` из отдельной ссылки обычным двойным щелчком. В нём собраны интерфейс и база слов. Для проверки нажмите «Карточки», «Тесты», «Словарь», «Mediatri». Этот пробный файл не устанавливает офлайн-PWA на телефон. На старом Safari локальное сохранение в file:// может зависеть от настроек браузера.

## Публикация на GitHub Pages с компьютера

1. Откройте https://github.com/new и войдите в свой GitHub-аккаунт.
2. Repository name: `riveria-sanasto` (новый отдельный репозиторий, не VELAR Music Manager).
3. Visibility: **Public** (для бесплатного GitHub Pages). Код приложения и встроенный учебный словарь станут публичными, но вашу приватную Google-таблицу и личные данные мы НЕ публикуем. Не включайте реальные данные пациентов.
4. Нажмите **Create repository**. Не обязательно отмечать `Add a README file`.
5. Распакуйте `Riveria-Sanasto-v1.0-GitHub-Pages.zip` на Mac (двойной щелчок по ZIP).
6. Откройте созданный репозиторий GitHub → **Add file → Upload files** (или ссылку **uploading an existing file**, если репозиторий пуст).
7. Выберите все файлы **изнутри распакованной папки**, не саму папку: `index.html`, `app.js`, `style.css`, `data.js`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `INSTALL_RU.md`. Скрытый `.nojekyll` не обязателен.
8. Внизу страницы нажмите **Commit changes**.
9. В репозитории откройте **Settings → Pages**. В разделе Build and deployment выберите **Deploy from a branch** → Branch: **main**, Folder: **/(root)** → **Save**.
10. Дождитесь надписи GitHub о публикации. После этого откройте адрес, показанный в Settings → Pages. Обычно он выглядит как `https://ИМЯ.github.io/riveria-sanasto/`.

## iPhone

1. Откройте опубликованный HTTPS-сайт в **Safari** (не в окне мессенджера).
2. Нажмите **Поделиться** → **На экран «Домой»** → **Добавить**.
3. Запустите приложение с новой иконки **при наличии интернета**. Откройте карточки и Mediatri, чтобы файлы загрузились.
4. Выключите интернет/включите авиарежим и проверьте, запускаются ли карточки с иконки.
5. Добавьте пробное слово, закройте приложение и откройте снова — убедитесь, что оно осталось.

## iPad mini 3 (iOS 12.5.8)

1. Откройте сайт в Safari, затем **Поделиться → На экран «Домой»**.
2. Запустите с иконки **хотя бы один раз онлайн**. У iOS 12 встречаются особенности изоляции кэша Safari и иконки на главном экране.
3. Проверьте авиарежимом, работает ли запуск офлайн. Не считайте эту совместимость подтверждённой, пока лично не проверили на iPad.
4. Для раннего тестирования используйте режим с простыми карточками, без установки новых браузеров.
5. Если офлайн-запуск с иконки не сработал, проверьте доступ через уже открытую вкладку Safari. Не удаляйте иконку, пока не сохраните резервную копию собственных слов.

## Компьютер

Откройте сайт в браузере и пользуйтесь им как обычным веб-приложением. После первичного визита в современных браузерах может работать кэширование для автономного доступа; для старого браузера проверьте офлайн режим вручную. На macOS Catalina новые версии браузеров уже не поддерживаются, но приложение намеренно написано с совместимым базовым JavaScript.

## Данные и безопасность

- Начальный словарь **встроен** в `data.js` и публичен при публикации на GitHub Pages. Это учебная лексика, не медицинские записи конкретных пациентов.
- «Добавить слово» записывает слово только в память данного устройства (`localStorage`). Не происходит автоматической записи в Google Sheets.
- Вкладка «Данные» позволяет скачать резервную копию .json и экспорт новых слов .tsv. Это нужно делать перед очисткой браузера или переносом на другое устройство.
- .tsv можно вручную открыть в Google Sheets, предварительно проверив дубли и структуру столбцов; не перезаписывайте существующий словарь вслепую.
- В Mediatri-тренажёре вводите только **вымышленные или обезличенные** ситуации. Лекарственные процедуры, применение ограничений и реальные записи — только по правилам учреждения и под наставничеством.
- Поиск русского описания работает на устройстве, **не является свободным машинным переводом**; он предлагает похожие готовые фразы.

## Обновление приложения

При обновлениях потребуется заменить файлы в GitHub, увеличить версию service worker (`CACHE_NAME`) и версии подключаемых файлов. Не меняйте домен/адрес без резервной копии: локальные данные привязаны к адресу сайта.

## Для следующего этапа

Настроить защищённую авторизацию Google и двустороннюю синхронизацию, с очередью офлайн-изменений, идентификаторами записей, проверкой конфликтов и отдельным резервным копированием. Не публиковать в открытом коде ключи доступа Google Sheets.
